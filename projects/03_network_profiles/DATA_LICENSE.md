# Data attribution and reuse

The Ookla tile subsets, county network summaries, clustering outputs and derived figures in this project are adaptations of **Speedtest by Ookla Global Fixed and Mobile Network Performance Maps**, for 2025 Q4 and 2026 Q1, accessed November 9, 2026 from the publisher's public AWS bucket.

Based on **Himanshu Jadaun's analysis**. Changes include geographic filtering, invalid-row exclusion, centroid-to-county assignment, county aggregation, statistical modelling and visualization.
